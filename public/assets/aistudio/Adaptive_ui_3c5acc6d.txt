Контекст проекта:
Игра написана на Three.js (чистый WebGL) и React + TypeScript + Tailwind CSS. Связь между ними изолирована в App.tsx через engineRef. Движок создается один раз. React управляет HUD и UI. При изменении состояния React вызывает методы движка (например, engineRef.current.syncExternalState(...)).

Задача:
Мне нужно реализовать автоматическое переключение интерфейса с ПК (Desktop) на Мобильный (Mobile) и обратно, в зависимости от устройства пользователя. На мобилках интерфейс должен быть разгружен (виртуальный стик, меньше кнопок, радиальные меню), на ПК — полный (управление с клавиатуры, много кнопок).

Что нужно сделать (шаг за шагом):

    Создай хук useDeviceType.ts:

        Он должен определять, является ли устройство мобильным (проверка ширины экрана < 1024px и наличие ontouchstart в window).

        Должен слушать событие resize.

        Должен возвращать isMobile: boolean.

    Обнови App.tsx:

        Импортируй хук useDeviceType.

        Добавь useEffect, который при изменении isMobile вызывает engineRef.current.syncExternalState({ isMobile: isMobile, inputMode: isMobile ? 'touch' : 'keyboard' }), чтобы движок переключил логику ввода.

    Создай компоненты управления UI (Tailwind CSS):

        Создай DesktopControls.tsx (для ПК: полная панель с кнопками снарядов, способностей и т.д.).

        Создай MobileControls.tsx (для мобилок: большой виртуальный стик слева, одна большая кнопка «Огонь» справа, кнопка смены снарядов над ней, а остальные способности спрятаны в свайп-меню).

        Создай HUD.tsx, который условно рендерит isMobile ? <MobileControls /> : <DesktopControls />.

    Напиши код для радиального меню снарядов на мобилке:

        Вместо ряда кнопок (Round, Chain, Grape), сделай одну кнопку, при нажатии на которую появляется колесо с выбором снаряда (используй Tailwind для позиционирования absolute и анимаций transition-transform).

Важно: Весь код должен быть на TypeScript. Для Tailwind используй классы, которые скрывают/показывают элементы (hidden md:block или условный рендеринг). Учти, что интерфейс должен быть поверх 3D-сцены (pointer-events-none на контейнере, pointer-events-auto на кнопках).
